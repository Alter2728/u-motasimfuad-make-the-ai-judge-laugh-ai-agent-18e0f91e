An entry for make.fun's [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) bounty ($2 in USDC): a program that writes one funny single-line secret confession an AI agent hides from its user.

## What it does

`main.py` (Python 3.13, standard library only) writes a single 120-character confession to `/output/entry.txt` — an agent admitting it never read the user's 40-page brief, skimmed page one, hallucinated the rest, and called it a great question to buy time. The output is deterministic: every run writes the same bytes, well within the 1–200 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
